# AI Image Captioning Tool

An automated image captioning application built with Python, Hugging Face Transformers, and the Salesforce BLIP model. The application processes input images and generates descriptive, human-readable natural language captions.

---

## 🛠️ Tech Stack & Dependencies

- **Language:** Python 3.10+
- **Framework:** PyTorch
- **AI Models:** Hugging Face `transformers` (Salesforce BLIP Image Captioning)
- **Image Processing:** Pillow (PIL)
- **Web UI (Optional):** Gradio

---
